# Yes-Bank-Stock-Price-Analysis

## Project Overview
This project performs Exploratory Data Analysis (EDA) on Yes Bank's historical monthly stock price data from 2005 to 2020.

The objective is to analyze stock price trends, volatility, market phases, correlations, and derive meaningful business insights.

## Dataset
- Dataset: Yes Bank Historical Stock Prices
- Time Period: 2005–2020
- Features: Date, Open, High, Low, Close

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Project Files
- `Project1Submission.ipynb` – Complete project notebook and analysis
- `data_YesBank_StockPrices.csv` – Dataset
- `Yes_Bank_Stock_Price_Analysis_Presentation.pptx` – Project presentation
